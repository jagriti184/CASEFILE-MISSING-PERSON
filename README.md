# 🔎 CASEFILE: AI-Powered Missing Person Investigation and Probable Location Prediction System

## 📌 Project Overview

**CASEFILE** is an AI-powered Missing Person Investigation and Probable Location Prediction System developed using Advanced Machine Learning techniques.

The system analyzes historical missing-person case data and uses Machine Learning to identify patterns, analyze case characteristics, predict probable locations, and support investigators in prioritizing search areas.

The system is designed as a **decision-support tool** and does not replace professional investigators or official investigation procedures.

---

## 🎯 Objectives

- Analyze historical missing-person case data
- Preprocess and clean investigation data
- Perform feature engineering
- Identify important factors affecting probable locations
- Apply Advanced Machine Learning algorithms
- Predict probable location/location categories
- Prioritize investigation/search areas
- Provide explainable ML predictions
- Support data-driven investigation

---

## 🧠 Machine Learning Techniques

The project explores multiple Machine Learning algorithms:

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Gradient Boosting
- Clustering
- Anomaly Detection
